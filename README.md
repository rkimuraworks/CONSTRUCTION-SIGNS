# SIGN MOTION — Construction Sign Web Demo

白い空間、透明ブルー、スクロール回転、動くピクトグラムを組み合わせた工事用看板のコンセプトデモです。

## ローカル確認
`index.html` をブラウザで開いてください。外部依存はGoogle Fontsのみです。

## GitHub Pages 公開
1. GitHubで新しい公開リポジトリを作成します。
2. `index.html`、`style.css`、`script.js` をリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deployment → Deploy from a branch を選択します。
4. Branch を `main`、フォルダを `/(root)` にして保存します。
5. 表示された GitHub Pages のURLから閲覧します。

## 編集箇所
- 配色：`style.css` の `:root` と各セクション
- 文字・構成：`index.html`
- スクロール連動：`script.js` の `update()`
- 物体：`index.html` 内のSVG。画像素材ではなく編集可能なベクター図形です。

※実在の工事用看板の法令適合性や印刷データの仕様を示すものではなく、演出確認用です。
